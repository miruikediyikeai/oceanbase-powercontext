# 数据流与设计

## 一次复习

浏览器读取 `/api/workspace` → 应用为服务端固定的学习者解析稳定 Scope → 从 PowerContext `/v1/memory/entries/list` 读取当前卡片与偏好 → 复习规则只选择到期卡片，优先最近自评为未记住的卡片 → 浏览器展示问题、答案和来源。

用户自评时，浏览器提交卡片 ID、等级和当前 `entry_version_id`。应用读取最新记录，比较版本，计算下一次复习时间，再向 `/v1/memory/entries/revise` 提交精确 citation。只有服务确认后才显示已保存。重新打开浏览器或重启应用会再次读取同一 Scope；应用不靠浏览器缓存恢复进度。

## 笔记转卡片

浏览器把整段 Markdown 交给 `/api/notes/segments`，服务端按标题（`#` 至 `######`）分段，跳过过短片段并限制单段长度。用户在浏览器里为每个段落补全问题与答案并勾选确认；只有确认的段落才随导入请求写入 Memory，未确认段落不存在于任何服务端状态中。卡片 ID 由主题、问题、答案、来源拼接后取 SHA-256 前 16 个十六进制字符并加 `note-` 前缀，内容相同则导入被识别为重复而跳过。

可选的语言模型候选生成只在后端三个环境变量同时配置时启用：请求发往 OpenAI 兼容的 `/chat/completions`，返回的候选仅用于浏览器表单回填，服务端不持久化候选。API 密钥只存在于后端环境变量中，前端与仓库均不可见。

## 复习历史与周汇总

PowerContext 的 Memory Artifact 保存不可变修订。单卡历史通过 `/v1/scopes/{scope_id}/artifacts/memory/memory/revisions/{n}` 从最新修订逐版回查：每次读取该修订的 manifest 条目，按 `entry_version_id` 变化识别修改，用该修订的 citation 调 `/v1/memory/entries/get` 读取当时的卡片快照。时间线包含导入、复习（自评等级）、遗忘次数变化与下次时间，每条标注 Memory revision 和 entry version。卡片在某个修订才出现时，该修订即导入事件；早于首版的时间线为空并返回 404，而不是编造记录。

周汇总遍历全部历史修订重建事件：复习按卡片快照中 `last_reviewed_at` 的实际变化计入当天；遗忘次数按相邻快照的 `lapses` 差值累加；新卡片按首次出现计入导入当天。统计范围固定为按 UTC 计算的最近 7 天（含今天），规则写入返回结果，无记录时明确返回空状态。周汇总只读不可变历史，不在本地重建持久化投影。

## 记录与身份

| 记录 | 作用 | 身份 |
| --- | --- | --- |
| Scope | 单个学习空间 | PowerContext 返回的 `scope_id`，由稳定 idempotency key 恢复 |
| `recall_card_v1` | 原始问题、答案、来源和当前学习状态 | 导入数据的稳定卡片 ID + PowerContext entry identity |
| `recall_preferences_v1` | 称呼和每轮卡片数 | 每个学习 Scope 唯一一条偏好记录 |
| citation | 可核对的历史证据 | Memory revision、entry ID 与 entry version ID |

每个卡片状态包含 `schema_version: 1`。更新保留卡片 ID，旧版本由 PowerContext 保管。计划和统计均为只读派生数据，不作为新的权威状态保存。导出的证据是一个时间点的读数，后续状态以 PowerContext 为准。

## 错误、并发和恢复

应用使用单进程锁串行处理一个学习空间的读改写。浏览器版本过期返回 409；底层服务返回版本冲突时也返回 409。无法连接服务时显示不可用，不切换为本地假记忆。连接错误不会自动重试写操作，用户先刷新核对结果。

卡片导入先验证所有输入和已存身份，再逐条写入。后续条目失败时已保存的条目不回滚；相同文件重新导入会跳过它们。未知 schema、重复卡片身份或偏好记录冲突时拒绝继续写入。首个空空间写入和跨进程并发未提供分布式唯一约束，因此该原型限定一个应用进程负责一个学习者。

## 范围

采用显式 Memory 读写，不依赖自动提取、语义检索、推理服务或 seekdb。模型仅作为可选候选生成器，未配置时全部功能可用。单次操作读取全部当前 Memory，最多支持 100 张卡片；尚未测量更大规模成本。复习规则是启发式，用户自行判断掌握程度，累计复习数不等于有效学习时长或学习效果。
